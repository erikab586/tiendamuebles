# Espacio Nórdico

Landing page responsive para una tienda de muebles y decoración, construida con Vue 3 y Vite.

## Requisitos

- Node.js 18 o superior
- npm

## Desarrollo

```sh
npm install
npm run dev
```

## Producción

```sh
npm run build
npm run preview
```

## Personalización

- Editá los productos, sus precios y sus imágenes en `src/App.vue`.
- Reemplazá `whatsappNumber` en `src/App.vue` por el número real en formato internacional, sin `+`, espacios ni guiones.
- Las imágenes de muestra y los precios son ilustrativos; reemplazalos por los materiales provistos por la tienda.
